# 2026-11-14 — `skladX01_v0`: мобильные вкладки в карточках клиента и поставщика

## Задача

На экранах уже 768px блоки карточек шли друг под другом и страница сильно
растягивалась. Нужно объединить их во вкладки, сохранив на десктопе текущую
двухколоночную раскладку. Вторая часть — карточка поставщика с блоками
«Полученный товар» / «Отданные деньги».

## Решения

| Вопрос | Решение |
|---|---|
| Angular Material из ТЗ | не подключаем: пакет установлен, но нигде не используется, темы нет; вкладки свои на CSS + signals |
| Карточка поставщика | на заглушках: API приходов/выплат поставщика пока нет |
| Где стили вкладок | глобально в `src/styles.scss` — иначе `client-detail.component.scss` (4.8 кБ) пробьёт бюджет `anyComponentStyle` 4 кБ |
| Дублирование разметки | блоки вынесены в `<ng-template>` и переиспользуются через `ngTemplateOutlet` |

## Что сделано

### Общий компонент

- `src/app/shared/tabs.component.ts` (+ `.spec.ts`) — `ITab { id, label, template }`,
  селектор `app-tabs`, `OnPush`. Разметка: `role="tablist"` с кнопками
  (`aria-selected`), панель `role="tabpanel"` рендерит только активный шаблон.
  Активная вкладка — `activeId()` (пустая строка = первая) + `computed` c типом
  `ITab | null`.

### Карточка клиента (`clients/client-detail.*`)

- `BreakpointObserver.observe('(max-width: 767.98px)')` → `toSignal` → `isNarrow()`.
- Блоки «Отпущенный товар» и «Принятые деньги» вынесены в
  `<ng-template #productBlock>` и `<ng-template #paymentBlock>`.
- `< 768px` → `<app-tabs>` с двумя вкладками; `>= 768px` → те же шаблоны подряд,
  без вкладок. Блок «КодСделки» остаётся сверху на всех разрешениях.

### Карточка поставщика (`suppliers/supplier-detail.*`)

- Новый роут `suppliers/:id` (объявлен выше `suppliers/:id/receipt/new`).
- `open()` в `suppliers-page.component.ts` теперь ведёт в карточку, а не сразу
  в форму прихода.
- Шапка: название, город, телефон, «← К поставщикам», кнопки «Принять товар»
  (существующая форма прихода) и «Выплатить» (disabled).
- Вкладки те же, что у клиента. Содержимое — пустые состояния с пояснением,
  что эндпоинтов приходов/выплат поставщика в SkladApi нет.

### Тесты

- `BreakpointObserver` в jsdom не работает (нет `window.matchMedia`) — в спеках
  подменяется на `{ observe: () => of({ matches, breakpoints: {} }) }`.
- Добавлены проверки: узкий экран → 2 вкладки и одна панель; широкий → блоки
  подряд и нет `app-tabs`; 404 поставщика.
