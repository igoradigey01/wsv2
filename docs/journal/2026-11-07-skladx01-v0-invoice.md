## Решения

- Накладная — **страница** `/clients/:id/invoice/new?dealId=…`, не диалог: в промте 17
  заложен отдельный экран с голосовым вводом.
- «Изменено» — демонстрационное: `changedProductIds` / `changedPaymentIds` + кнопка
  «Демо: подсветить»; удалить, когда API начнёт отдавать статус.
- «Последняя сделка» — последний элемент списка: API сортирует по `НомерСделки`,
  номера выдаются по возрастанию.
- Оформление — только через `var(--c-*)`; hex-коды в компонентах не пишем.
