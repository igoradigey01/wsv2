# Словарь предметной области

Термины, которые встречаются в коде, API и интерфейсе. Если слово в коде и в интерфейсе
расходится — в таблице указано, что считать правильным.

| Термин | Что это | Где |
|---|---|---|
| **Клиент** | покупатель, с которым ведутся взаиморасчёты | `dbo.Клиент`, `GET /api/clients` |
| **Сделка** | договорённость с клиентом; к ней привязаны накладные и платежи | `dbo.Сделка` |
| **КодСделки** | Guid-идентификатор сделки; это `id` в API и в UI | `Сделка.КодСделки` |
| **НомерСделки** | человекочитаемый номер `R-000151`, уникален, выдаётся последовательностью | `Сделка.НомерСделки` |
| **LegacyId** | номер метки в эталоне `Sh_29-06-25`; только аудит переноса, в API не используется | `Сделка.LegacyId` |
| **Метка расчёта** | устаревшее название сделки (из эталона); в новом UI — «КодСделки» | старое имя DTO `МеткаРасчетDto` |
| **Накладная** | шапка отгрузки: номер, дата, клиент, сделка | `dbo.НакладнаяРасход` |
| **Расход** | строка накладной: номенклатура, количество, сумма | `dbo.Расход` |
| **Деньги** | платёж или возврат по сделке | `dbo.Деньги`, `OperationType` |
| **Отгружено** | сумма строк «Расход» по накладным сделки | `vw_БалансСделки` |
| **Оплачено** | приход минус возвраты по сделке | `vw_БалансСделки` |
| **Долг** | `Отгружено − Оплачено`; **не хранится**, считается представлением | `vw_БалансСделки` |
| **Переплата** | `max(0, Оплачено − Отгружено)`; в UI показывается как отрицательный долг | `vw_БалансСделки` |
| **Предел кредита** | допустимый долг клиента | `Клиент.ПределКредита` |
| **Номенклатура** | справочник товаров | `dbo.Номенклатура` |
| **UETR** | идентификатор накладной из эталона, перенесён без изменений | `НакладнаяРасход.UETR` |

## Правила именования

- В API и UI сделка называется сделкой: `dealId`, `сделкаId`, `КодСделки`. Слово «метка»
  осталось только в исторических именах классов (`МеткаРасчетDto`) и в промтах.
- В шаблонах Angular — только латиница (`{{ client.alias }}`), кириллица даёт `NG5002`.
- В JSON ключи кириллические, но в camelCase: `псевдоним`, `сделкаId`, `пределКредита`.
