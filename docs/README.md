# Документация wsv3 (Nx-монорепо)

Задачи, журнал, справочник и шпаргалки по фронтенду. Код приложений — в `apps/`,
общие библиотеки — в `libs/`.

## Структура

| Каталог | Что внутри | Статус |
|---|---|---|
| [`help/`](help/) | `deploy.md` — сборка и выкладка (Nx 24 / Angular 22), `git.md` — шпаргалка по веткам | актуально |
| [`journal/`](journal/) | записи по датам: что сделано, какие коммиты | актуально |
| [`reference/`](reference/) | [`glossary.md`](reference/glossary.md) — словарь предметной области | актуально |
| [`tasks/`](tasks/) | задачи по приложениям | см. таблицу ниже |
| [`prompts/`](prompts/) | шаблоны промтов для новых приложений | актуально |
| [`help_old/`](help_old/) | старые шпаргалки (Angular, Nx, Docker, деплой и др.) | **архив**: не пополнять, только читать |

## Правила для документов

1. Задача не удаляется после выполнения — статус ставится первой строкой после заголовка:
   `**Статус:** выполнено | частично | план | архив`.
2. Журнал — файл `journal/YYYY-MM-DD-тема.md`; в нём коммиты, решения и незакрытые хвосты.
3. Новые шпаргалки — только в `help/`; `help_old/` не пополняется и не чинится,
   кроме битых ссылок.
4. Пути и имена проектов — из хаба: `/mnt/developer/_hubx01/AGENTS.md`, раздел 3.
5. Исторические имена (`skladx01`) в старых задачах не переписываются — они помечаются
   в статусе; актуальные каталоги: `apps/skladsh`, `apps/skladX01_v0`.
